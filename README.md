# ga21-timeline

Event timeline for the Spiceworks Myanmar 21st General Assembly (Friday, November 27, 2026).

- Times are stored in Asia/Yangon and can be shown in Yangon, Tokyo or Manila time (defaults to the viewer's browser time zone).
- Live tracking shows the current session, a countdown and progress along the timeline.
- Preview a moment of the event with `?now=`, e.g. `?now=2026-11-27T13:50:00+06:30`.
